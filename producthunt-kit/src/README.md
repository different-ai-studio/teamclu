## ⚠️ 一条硬规则：不要把整个窗口直接发出去

TeamClu 的会话列表会显示**会话标题和消息预览**。这台机器上的真实数据里出现过：

```
WeCom group: wrOOCIYgAAze..            （企业微信群 ID）
**今天（9/15）核销额：767.26元，24笔..    （真实经营数字）
用ngrok分享本地模型
我想获取https://life.douyin.c..
```

所以 `group-session.png` 是**只裁了中间对话列**（695×640），列表列被切在画面外。
再拍时请保持同样的规则：**先 OCR / 肉眼扫一遍，确认没有内部数据再合成。**

合成后也建议复扫一次，例如：

```bash
# 用任意 OCR（macOS 可用 Vision）扫成品图
# 关键词：核销、WeCom、ngrok、wrOOC、内网域名、真实人名
```

## 想要完整三栏版（含参与者头像）

完整三栏对「群聊」更有说服力（能看到 2 位 / 3 位 的参与者头像簇），但需要干净的数据：

1. 用一个**演示团队 / 演示工作区**（英文界面、造几条 skill 和会话），或
2. 先把含业务数据的会话归档

然后覆盖 `group-session.png` 重跑脚本。若换了画面比例（比如横向的完整窗口），
脚本会自动按高度适配，不用手改尺寸。

## 其他可选镜头

`role-picker.png`：在输入框敲 `/` 弹出的 `CommandPopover`，同时展示 **Roles / Skills / Commands** 三组。
讲「Role 是一组 skill 的命名组合」时有用。加进 `scripts/build-producthunt-gallery.mjs` 的 `SCENES` 即可。

## 拍之前

- 用**英文界面**：PH 主流量是英文区（当前两张是中文界面，若要英文版需要应用切语言后重拍）。
- 分辨率用应用原生窗口（1200×800）即可，脚本会缩放进卡片。
- 不要出现真实客户数据、仓库路径、token、邮箱、同事真名。
