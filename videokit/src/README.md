# 英文截图投放点

把在**英文界面**下重拍的真实截图放这里，重跑 `node videokit/build-video.mjs`
就会自动改用真实截图，不用改代码。

| 文件名 | 对应 | 要拍到的东西 |
|---|---|---|
| `assign-en.png` | ① ASSIGN | 一个会话里 @提及一个 agent，它作为参与者回复。要看得见参与者头像簇和在线状态 |
| `compound-en.png` | ④ COMPOUND | 技能详情：版本列表、changelog、冲突/恢复入口 |

不放文件时构建会打印 `using the … spec diagram`，**不会静默降级**。

## 拍摄要点

1. **应用切英文界面**再拍。这是重点——仓库里现有的每张真实截图都是中文界面下
   拍的，这是它们进不了这条片子的唯一原因。
2. **用演示团队，不要用真实业务数据。** `producthunt-kit/README.md` §4 记过一次
   教训：OCR 扫图时在截图里扫出了真实的企业微信群 ID 和真实经营数字。
3. 会话标题、人名、技能名都用编的，别用真名（PH kit §7 已确认 maker 是 Bertrand，
   截图里出现真实同事姓名不合适）。
4. 窗口宽度 ≥1270，缩到 1080 高是 1.42× 放大。

## 不要做的事

- **不要 P 掉中文，也不要拼贴改字。** 规格图是明写「这是示意图」的；把中文截图
  修成英文会让它变成一张没人能验证的图。
- 如果改用真实截图后某一站的构图不如规格图清楚，先比一比再决定——现在这两帧
  承载的是「群聊」和「团队资产」两个主主张，画面必须能自证。
