A new version is verified before it replaces this one. The daemon waits until no turn is running to restart into it, and goes back to the previous version if the new one keeps failing to start. Changes here apply after a restart. To update right away, run amuxd update.

Daemon config

Values are written to daemon.toml and validated before saving — an invalid edit is rejected and the file left untouched. Credentials are never sent back to this page; leave a field blank to keep the stored value.
